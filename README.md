# 云游中国 · 旅游景点介绍网站

基于开题报告《基于 PHP 的旅游景点介绍网站设计与实现》完成的前后台一体化网站原型。
本版本为**可直接在浏览器中运行**的演示版（纯 HTML/CSS/JS，数据用 localStorage 模拟 MySQL），
完整覆盖开题报告中的全部功能模块，并在此基础上做了丰富与美化。

## 一、如何打开

1. 推荐方式：双击 `启动网站.bat`，会自动启动本地服务并打开浏览器（地址 `http://localhost:8000`）。
   这样前台与后台数据能稳定共享，后台的修改刷新后即可在前台看到。
2. 也可以直接双击 `index.html`（Chrome / Edge），但个别浏览器会隔离本地文件的存储，
   可能出现“后台改了、前台不变”的情况，此时请改用 `启动网站.bat`。
3. 前台浏览无需登录；注册/登录后即可收藏景点、发表留言评论。
4. 后台入口：首页页脚「后台管理入口」，或直接打开 `admin/login.html`。

## 三、功能对照（开题报告 → 本站实现）

**前台游客浏览系统**

- 景点浏览：全部景点列表、按分类筛选、关键词搜索、按热度/评分/名称排序、分页。
- 景点详情：介绍、图片（封面+图集）、开放时间、门票参考、交通提示、详细地址、游玩攻略。
- 旅游资讯：资讯 / 攻略 / 公告分类，资讯详情页。
- 留言评论：登录用户可星级评分 + 文字留言，查看其他游客留言。
- 用户模块：注册、登录、修改昵称、修改密码、我的收藏、我的留言。

**后台管理系统（管理员）**

- 仪表盘：景点/用户/留言/资讯统计、分类分布图、最新留言、站点设置。
- 用户管理：查看、搜索、启用/禁用、重置密码、删除用户。
- 景点管理：新增、编辑、删除、查询、上下架，上传封面图片与图集。
- 资讯管理：发布、修改、删除、上下线资讯。
- 留言管理：查看、隐藏/恢复、删除留言。

## 五、数据与图片说明

- 景点介绍、开放时间、门票等为**演示参考数据**，正式答辩请以景区官方最新信息为准。
- 景点图片为从携程、去哪儿、知乎、人民网等公开旅行/资讯平台检索并本地化的**真实照片**，
  已自动过滤 699pic、视觉中国、图虫等带水印的图库来源，每张对应其景点主题（封面 + 图集共 3 张/景点）；
  在后台“景点管理”中也可直接**上传自己的照片**替换。
- 后台上传的图片会自动压缩到合适尺寸，避免浏览器存储超限导致“保存后前台不更新”。
- 图片来源于网络公开搜索，仅用于课程/毕业设计演示，请勿商用；正式提交时建议替换为自行拍摄或已获授权的照片。
- 数据层 `store.js` 的字段结构与 MySQL 表一一对应，可平滑移植到 PHP + MySQL：
  `attractions`、`news`、`users`、`comments`、`settings` 五张表。

## 六、移植到 PHP + MySQL 的建议

1. 用 `attractions`、`news`、`users`、`comments`、`settings` 建表（字段见 `store.js` 种子数据）。
2. 把 `store.js` 中的读写操作替换为 PHP 接口（如 `api.php?action=list&table=attractions`）。
3. 登录与留言改用服务端 Session 校验，密码使用 `password_hash()` 存储。
